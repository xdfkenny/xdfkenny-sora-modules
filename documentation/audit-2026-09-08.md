### Diagnosis detail

- **hydrahd-shirox = harness artifact.** Both `hydrahd.json` and
  `hydrahd-shirox.json` point `scriptUrl` at the same `hydrahd/hydrahd.js`.
  The test harness had loaded a stale local `hydrahd/hydrahd-shirox.js`
  (old variant). Re-test loading `hydrahd.js` → PASS.
- **torrentio = WAF on egress IP.** `torrentio.strem.fun` 403s on every path
  (`/`, `/health`, stream URLs) from this network; `v3-cinemeta.strem.io`
  (search + meta dependency) works, so search/episodes still pass. Known issue
  (e.g. TheBeastLT/torrentio-scraper#403); not actionable in-module.
- **allmanga NEED_CAPTCHA is IP/rate-based, not a code defect.** The live
  audio-mask flow now yields build-166 (epoch 2957, lane k7) keys; when the
  Cloudflare flag clears the module produces real HLS again (previously
  verified in-browser).
- **anidb 503** — site-wide maintenance page (returns the same 503 for every
  route); scrape markup unchanged (DB): no module change sensible until the
  site comes back.

## 3. AnimeNexus deep-dive (stream protection)

Full evidence chain in `documentation/anime-nexus-stream-protection.md:1`.
Summary: stream *metadata* works with fingerprint headers + session cookie,
but the HLS manifest and every segment require tokens from a WebSocket-only,
attestation-gated token service (`prd-socket.anime.nexus`, namespace `/video`,
Turnstile/altcha + AES-GCM wire secret). Infeasible in the fetchv2-only,
WebSocket-less Sora runtime; only a self-hosted token proxy could make it
playable. Module stays in the registry as searchable.

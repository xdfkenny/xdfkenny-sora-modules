help FAQ

Answers to common questions about installing and using Sora modules.

On this page, click the "Add to Sora" button on any module card. This opens the Sora app and automatically installs the module. You can also copy the JSON link and paste it manually in Sora → Settings → Modules → Add Module.

The sora:// deep-link only works on iOS or macOS with the Sora app installed. On Android or Windows, copy the JSON link manually instead. If you're on Safari/Chrome iOS, make sure you have Sora installed from the Sora website.

The source site may be temporarily down or the module may need updating. Check the GitHub repo for the latest version and open an issue if it persists.

Yes — most modules here support Sora and Luna. Some (like HydraHD Shirox) are tailored for Shirox. Each module card shows its app compatibility badges so you can identify which apps are supported at a glance.

Use the Manifest Creator above to generate your module.json manifest. Then read the Sora Module Documentation and open a pull request on the GitHub repository.
